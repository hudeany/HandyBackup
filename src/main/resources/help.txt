Usage:
	java -jar HandyBackup.jar [gui]
	or
	java -jar HandyBackup.jar devices
	or
	java -jar HandyBackup.jar backup [-serial <serial number>] [-delete] [-v]
	or
	java -jar HandyBackup.jar version | update | help

Commands and parameters may be written with or without leading "-" (e.g. "backup" or "-backup").
Phones are connected via USB in "File transfer" (MTP) mode. Shares, phone assignments and the
per-phone settings (deletion, folders excluded from deletion, additional backup folders) are
configured once in the GUI and stored in ~/.HandyBackup/.HandyBackup.devices.config.

Commands
	gui:
		Open the GUI (default without any command)
	devices:
		List the connected phones with serial number, assigned share and deletion setting
	backup:
		Back up all connected phones that are assigned to a share. Backed up are the default folders
		(images, videos, music, contacts or all files, depending on the folder) and the folders added
		per phone in the GUI (context menu "Add to backup ..." of the phone tree) with their file types
	version:
		Show the current local version of this tool
	update:
		Check for an online update and ask, whether an available update shall be installed
	help:
		Show this help manual

Optional parameters for backup
	-serial <serial number>:
		Back up only the phone with this serial number (see command "devices")
	-delete:
		After a complete backup, delete backed-up files from the phone according to the phone's setting
		"Delete from phone after ... days" (-1 = never, 0 = all backed-up files, x = older than x days).
		Only files whose copy is verified on the share are deleted.
		Folders excluded from deletion (context menu "Exclude from deletion" in the GUI) are never deleted.
		Music, Ringtones, Notifications, Podcasts, Recordings and Audiobooks are excluded by default.
		Without this parameter nothing is deleted on the phone, only the number of deletable files is shown.
	-v:
		Verbose output with progress display

Exit codes
	0: Success
	1: At least one error occurred
	2: No connected (and assigned) phone found
	3: Invalid command line

Example for a scheduled backup (Windows task scheduler):
	java -jar HandyBackup.jar backup -delete

Ctrl+C cancels a running backup after the current file; the backup index is saved before exiting.
