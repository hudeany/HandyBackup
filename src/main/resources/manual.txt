HandyBackup - Backup of photos, videos and other files from Android phones to a Samba share

REQUIREMENTS
- Windows (the phone is accessed via the Windows device drivers, MTP)
- Phone connected via USB, unlocked and set to "File transfer"
- A Samba share in the local network with user and password

GETTING STARTED
1. Open "Shares ..." and create a share: server, share, optionally a subfolder,
   user and password. "Test connection" checks the settings.
2. Connect the phone and click "Search devices".
3. Select the share for this phone under "Backup target". The phone is recognized by its
   serial number, so the assignment only has to be made once. Several phones can be assigned
   to one share, e.g. the old and the new phone of the same person.
4. Click "Start backup".

DISPLAY
The left side shows the folder tree of the phone. Folders shown in bold are backed up.
The right side shows the folder tree of the assigned share.
A double click (or Enter) on a file opens it with the system's default application,
e.g. images in the photo viewer. For this, a copy is loaded into a temporary folder.
Selected files on the phone or on the share can be deleted via the context menu (right mouse button)
or the Delete key. A confirmation is always shown first. For the phone it shows whether the files
are backed up, for the share whether the files are still on the connected phone.
Deleting on the share also removes the entries from the index; if the file is still on a phone,
it is backed up again with the next backup. The folder ".handybackup" is protected.

WHAT IS BACKED UP
Files are backed up per folder by file type:
  Images    jpg, jpeg, png, heic, heif, gif, webp, bmp, dng
  Videos    mp4, mov, 3gp, 3g2, mkv, webm, m4v, avi
  Music     mp3, ogg, wav
  Contacts  vcf
  All       all files, no filter by extension
Backed up by default (including subfolders):
  DCIM, Movies                               images and videos
  Pictures                                   images
  Android/media (WhatsApp, Telegram ...)     images and videos
  Download, Downloads, Documents, Telegram   all files
  Music, Ringtones, Notifications            music
  Podcasts, Recordings, Audiobooks           all files
For nested folders the most specific one decides, e.g. "WhatsApp Images" only images, "WhatsApp Video" only videos.
Hidden folders (e.g. thumbnails and trash), WhatsApp ".Statuses" as well as the WhatsApp folders
"Sent" and "Private" are not backed up.

Further folders can be added to the backup per phone via the context menu of the phone tree
("Add to backup ..."), choosing the file types to back up from the folder and its subfolders.
This also works for a default folder or one of its subfolders: the most specific folder always decides,
so e.g. only images can be backed up from a subfolder of "Download".
The tooltip in the tree shows the backed-up file types and where they come from. The context menu also
allows changing the file types later ("Change backed-up file types ...") or removing the folder again
("Remove from backup"). A folder added explicitly is backed up even if it is hidden (name starting with
a dot). This setting is only possible for phones with an assigned share and is also used by backups
from the command line.

STORAGE ON THE SHARE
<subfolder>/<year>/<year-month>/<original file name>
If another file with the same name already exists there, "_1", "_2" etc. is appended.
The backup itself never overwrites or deletes anything on the share.

DUPLICATE FILES
The folder ".handybackup" of the share contains an index of all backed-up files with checksum.
Files already backed up are skipped next time without transferring them again.
Files with the same content are stored only once, even if they come from another phone.

CANCEL
"Cancel" ends the backup after the file currently being transferred. The next run
continues with the files still missing.

DELETING ON THE PHONE
Next to the device information there is "Delete from phone after ... days". The setting applies
per phone (serial number), the default is 90 days:
  -1  never delete
   0  delete all backed-up files
   x  delete backed-up files older than x days
Files are only deleted after a complete, not cancelled backup and only after a confirmation
showing the number and size of the files. A file is only deleted if it is in the index and
its copy with the correct size is on the share. Files with unknown date are only deleted
with 0. If a file on the phone was changed since the backup, it is kept.
Single folders can be excluded from this deletion via the context menu of the phone tree
("Exclude from deletion"). The exclusion applies per phone and includes all subfolders; such folders
and their files are marked with a color. It is removed at the same folder via the context menu.
The folders Music, Ringtones, Notifications, Podcasts, Recordings and Audiobooks are excluded from deletion
by default. Unchecking the item there allows deletion on this phone; the folder is then marked with
"(deletion allowed)".
Manual deletion via the context menu stays possible, the confirmation then points this out.
